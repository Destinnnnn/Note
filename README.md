# 计算机组成原理笔记

课程来自 B 站湖科大。

建议导入 Obsidian 中使用，并保留 `assets/` 资源目录，否则笔记中的 PPT 截图无法正常显示。

## 下载选择

原版保留在仓库根目录；图谱版放在独立目录中。

| 版本 | 内容 | 适合场景 |
| --- | --- | --- |
| [原版单文件](./计算机组成原理.md) | 一个 Markdown 主文档 + 根目录 `assets/` 图片资源 | 想快速阅读或只维护单个文档 |
| [图谱版](./计算机组成原理-图谱版/) | 按章节拆分的多 Markdown 文档 + 双链关系 + 独立 `assets/` | 想在 Obsidian 中查看关系图谱、按知识点跳转 |

图谱版入口文件：[计算机组成原理-图谱版/计算机组成原理.md](./计算机组成原理-图谱版/计算机组成原理.md)。

## 使用方式

1. 点击 GitHub 页面右上角 `Code`，选择 `Download ZIP` 下载仓库。
2. 解压后，用 Obsidian 打开仓库目录。
3. 阅读原版时打开根目录的 `计算机组成原理.md`；阅读图谱版时打开 `计算机组成原理-图谱版/计算机组成原理.md`。
