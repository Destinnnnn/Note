# 计算机组成原理笔记

课程来自 B 站湖科大。

建议导入 Obsidian 中使用，并保留 `计算机组成原理-图谱版/assets/` 资源目录，否则笔记中的 PPT 截图无法正常显示。

## 内容

本仓库仅保留图谱版，按章节拆分为多个 Markdown 文档，并通过双链组织知识点。

图谱版入口文件：[计算机组成原理-图谱版/计算机组成原理.md](./计算机组成原理-图谱版/计算机组成原理.md)。

## 使用方式

1. 点击 GitHub 页面右上角 `Code`，选择 `Download ZIP` 下载仓库。
2. 解压后，用 Obsidian 打开仓库目录。
3. 打开 `计算机组成原理-图谱版/计算机组成原理.md` 开始阅读。
