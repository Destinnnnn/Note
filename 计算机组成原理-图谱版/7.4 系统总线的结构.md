## 7.4 系统总线的结构
- 系统总线是连接 [[1.3 计算机硬件#1.3 计算机硬件|CPU]]、主存、I/O 模块等主要功能部件的信息主干。
- 中提到，系统[[7.1 总线概述#7.1 总线概述|总线]]也可称为主机总线、CPU 总线、前端总线 FSB 等。

- 系统总线结构主要包括：

| 结构 | 特点 |
| --- | --- |
| 单总线结构 | 所有部件通过一组总线连接。 |
| 双总线结构 | 将高速部件和低速 I/O 部件分离到不同总线。 |
| 三总线结构 | 常见为[[4.1 存储器概述#4.1.3 主存的基本结构|主存]]总线、I/O 总线等多级连接。 |
| 高性能总线结构 | 通过更高带宽的点到点互连提升性能。 |

- 单总线结构：
	- 结构简单，成本较低。
	- 所有部件共享同一总线，容易形成瓶颈。
- 双总线结构：
	- 可将主存访问和 I/O 访问分离。
	- 有利于减轻单总线负担。
- 三总线结构：
	- 通过不同层级总线连接 CPU、主存、I/O 设备等。
	- 图中出现 HOST 总线、PCI 总线、ISA 总线等层次。
- 高性能总线结构：
	- 用更高速的互连方式连接 CPU、芯片组、内存和外设。
	- 对比了从传统北桥/南桥到现代平台控制器的变化。
	- *随着集成度提高，部分原来由芯片组承担的功能被集成到 CPU 内部。*
