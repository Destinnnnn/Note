## 1.3 计算机硬件

- 早期 ENIAC：
	- 采用十进制。
	- 没有内存储器。
	- 需要通过旋钮、开关和接插线的不同位置来表示程序。
	- 程序修改耗时很长，使用者需像硬件工程师一样工作。

- 冯·诺依曼结构引入了==存储程序==思想：
	- 程序先通过穿孔介质输入机器。
	- 之后长期驻存在机器内部的存储器中。
- 冯·诺依曼计算机的主要特点：
	- ==以运算器为中心==
	- 构成程序的指令和数据均采用==二进制==表示。

### 计算机硬件的组成

- 计算机硬件由 5 大部件组成：
	- 运算器
	- 控制器
	- 存储器
	- 输入设备
	- 输出设备

| 部件   | 说明                          |
| ---- | --------------------------- |
| 存储器  | 用于存放程序和数据。                  |
| 运算器  | 主要功能是算术运算和逻辑运算。             |
| 控制器  | 用于解释存储器中的指令，并发出各种操作命令来执行指令。 |
| 输入设备 | 将用户信息送入计算机。                 |
| 输出设备 | 将计算机处理结果输出。                 |

- 现代计算机结构通常以==存储器为中心==。
	![[Pasted image 20260721094654.png]]
	- 主存储器用于存放程序和数据，可以直接与 [[1.3 计算机硬件#CPU 内部部件|CPU]] 交换信息，又称内存储器，简称内存或主存。
	- 辅助存储器用于长期保存更多信息，CPU 要处理辅助存储器中的信息时，需要先调入[[4.1 存储器概述#4.1.3 主存的基本结构|主存]]。
	- 运算器和控制器合在一起形成中央处理器 CPU。
	  ![[Pasted image 20260701152309.png]]

### CPU 内部部件

| CPU 内部部件                                      | 说明                              |
| --------------------------------------------- | ------------------------------- |
| 算术逻辑单元 [[1.6 计算机的基本工作原理#运算器中出现的寄存器和部件\|ALU]] | 完成加、减、乘、除等算术运算，以及与、或、非、异或等逻辑运算。 |
| 控制单元 CU                                       | 分析存储器中的指令，并发出各种操作命令来执行指令。       |
| 相关寄存器                                         | 配合 ALU 和 CU 暂存信息。               |
