## 1.4 计算机软件

- 计算机软件可以分为两大类：
	- 应用软件
	- 系统软件

| 软件类型 | 定义                                             | 示例                                  |
| ---- | ---------------------------------------------- | ----------------------------------- |
| 应用软件 | 为解决某个应用领域的相关问题而编制的程序。                          | 科学计算程序、工程设计程序、数据处理程序、企业管理程序、自动控制程序。 |
| 系统软件 | 为了用户能够高效、安全地使用和管理计算机硬件资源，以及为开发和运行应用软件而编制的各种软件。 | [[1.4 计算机软件#1.4 计算机软件\|操作系统]]、数据库管理系统、语言处理程序、服务程序等。          |

- 语言处理程序包括：
	- 汇编程序
	- 编译程序
	- 解释程序

- 计算机软件的发展大致经历：

| 阶段               | 特点                                       |
| ---------------- | ---------------------------------------- |
| 机器语言编程（早期）       | 直接使用机器指令（二进制编码），计算机可以直接执行，但编程、调试和维护都很困难。 |
| 汇编语言编程（20世纪50年代） | 用助记符表示机器指令，需要通过汇编程序翻译成机器语言程序。            |
| 高级语言编程（20世纪60年代） | 用接近自然语言和数学公式的形式编写程序，通常需要编译或解释后才能执行。      |

- 高级语言程序转换为可执行目标程序的主要过程：
	- 预处理
	- 编译
	- 汇编
	- 链接

- 随着硬件和软件的发展，人们又创造出操作系统。
	- 操作系统属于==系统软件==。
	- 操作系统提供了==在使用汇编语言和高级语言的过程中所需的某些基本操作。==
	- 操作系统==控制并管理计算机系统的全部 [[1.3 计算机硬件#^computer-hardware-components|硬件资源]]（CPU，内存和外部设备等等）和 软件资源（编译程序，应用程序等等）==。
	- 操作系统为用户使用计算机系统提供方便条件。
