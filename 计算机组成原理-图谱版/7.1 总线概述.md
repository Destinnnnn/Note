## 7.1 总线概述

### 7.1.1 作用和特点、主从设备、标准规定的四个特性
- 在计算机中，总线是用于在各功能部件之间传输数据的一组==公共通信线路==。
	- 功能部件包括 [[6.1中央处理器概述#6.1中央处理器概述|CPU]]、[[4.1 存储器概述#4.1.3 主存的基本结构|主存]]、I/O 设备等。
	- 总线可以减少部件之间连线数量，使系统结构更清晰。

- 总线有两个主要特点：
	- ==共享==：所有功能部件都挂接在总线上，基于总线传输数据。
	- ==分时==：同一时刻只允许一个功能部件向总线发送数据，但多个功能部件可以同时从总线上接收相同数据。
- 在基于总线的通信过程中，不同功能部件的角色不同：

| 角色 | 含义 |
| --- | --- |
| 主设备 | 获得总线控制权，主动发起一次或多次传输操作的功能部件。 |
| 从设备 | 没有总线控制权，只能响应主设备请求的功能部件。 |

- 不同厂商设备要接入同一总线，必须遵循统一的总线标准。
- 总线标准通常规定以下 4 个特性：

| 特性 | 含义 |
| --- | --- |
| 机械特性 | 插头、插座、引脚数量、排列方式、尺寸和固定方式等。 |
| 电气特性 | 信号电平、传输方向、有效电平、驱动能力等。 |
| 功能特性 | 每条信号线的功能，例如地址线、数据线、控制线等。 |
| 时间特性 | 信号出现的先后顺序、持续时间和时序配合。 |

### 7.1.2 分类
- 总线可以从多个角度分类。
**1.按传输方向分类**

| 类型   | 含义           |
| ---- | ------------ |
| 单向总线 | 信息只能沿一个方向传输。 |
| 双向总线 | 信息可以沿两个方向传输。 |
**2.按时序控制方式分类**

| 类型   | 含义                           |
| ---- | ---------------------------- |
| 同步总线 | 传输双方由一个公共时钟信号控制，通信按预定的时钟周期进行 |
| 异步总线 | 无公共时钟信号，通信靠双方之间的握手信号来协调      |

**3.按总线功能分类**

| 类型 | 作用 |
| --- | --- |
| 地址总线 | 用于传送地址信息。 |
| 数据总线 | 用于传送数据信息。 |
| 控制总线 | 用于传送控制信号、状态信号、请求信号、握手信号等。 |

- 地址总线通常用于指出[[4.1 存储器概述#4.1.3 主存的基本结构|主存]]单元或 I/O 端口地址。
	- 地址总线位数决定可寻址空间大小。
- 数据总线用于在部件之间传送数据。
	- 数据总线宽度决定一次可同时传输的数据位数。
- 控制总线用于控制一次总线传输过程。

**4.按传输模式分类**

| 类型   | 特点               |
| ---- | ---------------- |
| 并行总线 | 多位数据同时传输，线路数量较多。 |
| 串行总线 | 数据按位顺序传输，线路数量较少。 |

**5.按总线所在位置分类**

| 类型                    | 说明                             |
| --------------------- | ------------------------------ |
| 片内总线                  | 芯片内部各部件之间使用的总线。                |
| [[7.4 系统总线的结构\|系统总线]] | CPU、主存、I/O 模块等主要功能部件之间的信息主干。   |
| I/O 总线                | 用于连接 I/O 设备或 I/O 控制器。          |
| 外部总线                  | 也称通信总线，用于计算机系统之间或计算机与外部设备之间通信。 |

### 7.1.3 性能指标
- 总线的常见性能指标包括：

| 指标 | 含义 |
| --- | --- |
| 总线宽度 | 总线中数据线的位数。 |
| 总线时钟频率 | 总线时钟信号的频率。 |
| 总线工作频率 | 单位时间内总线传输的次数，也称有效频率、等效频率或数据传输率。 |
| 总线传输周期 | 一次总线传输所需时间，通常包含多个总线时钟周期。 |
| 总线带宽 | 总线上单位时间内最多可传输的数据量。 |
| 总线负载能力 | 总线能够挂接设备、驱动设备的能力。 |

- 总线时钟频率是总线时钟周期的倒数。
- 总线工作频率表示一个总线时钟周期内可传输数据的次数。
	- SDR：单倍数据率。
	- DDR：双倍数据率。
	- QDR：四倍数据率。
- 总线带宽通常与总线宽度、总线工作频率有关。
	- 总线越宽，一次传输的数据位数越多。
	- 工作频率越高，单位时间内可完成的传输次数越多。
- 计算机系统总线通常追求更高带宽和更强负载能力，但二者之间可能存在矛盾。
	- 例如提高并行总线的时钟频率会加剧信号同步和干扰问题。
