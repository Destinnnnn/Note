## 6.3 数据通路
### 6.3.1 CPU内部单总线结构
- 数据通路指数据在各功能部件之间传送的路径
	- cpu内部的数据通路是指各运算器与寄存器之间的数据传送路径
- 数据在数据通路的传送操作需要在控制信号的控制下进行
- 数据通路的基本结构分为：
	- 总线
	- 专用通路

**2.CPU内部主要组件**

| 组件             | 名称                        | 含义与作用                                                                 |
| -------------- | ------------------------- | --------------------------------------------------------------------- |
| `PC`           | 程序计数器                     | 程序计数器保存下一条要执行指令的地址。取指时，PC 的内容送往 MAR；顺序执行时，PC 通常加 4 或加 1。              |
| `IR`           | 指令寄存器                     | 保存当前正在执行的指令。指令从主存取出后送入 IR，再由指令译码器分析。                                  |
| `指令译码器`        | Instruction Decoder       | 对 IR 中的操作码、寄存器字段、地址字段等进行译码，告诉控制器当前指令需要哪些操作。                           |
| `时钟`           | Clock                     | 提供节拍信号，使 CPU 内部操作按时间顺序进行。                                             |
| `操作控制器`        | Control Unit / Controller | 根据指令译码结果、时钟、状态标志和[[6.5 异常与中断#6.5 异常与中断\|中断]]信号，产生各种控制信号。              |
| `X`            | 暂存寄存器                     | 暂存 ALU 的一个操作数。由于图中 CPU 采用单总线结构，ALU 的两个输入不能同时都直接来自总线，所以需要 X 暂存其中一个操作数。 |
| `ALU`          | 算术逻辑单元                    | 执行加法、减法等算术逻辑运算，并产生运算结果和状态标志。                                          |
| `Z`            | 结果暂存寄存器                   | 保存 ALU 的运算结果。ALU 结果不能直接长期停留在总线上，通常先送入 Z，再由 Z 输出到内部总线。                 |
| `PSW`          | 程序状态字寄存器                  | 保存 ALU 运算产生的状态标志，如溢出、进位、符号、零标志等。                                      |
| `R# / W# 寄存器组` | 通用寄存器组                    | 保存通用数据。`R#` 表示读寄存器编号，`W#` 表示写寄存器编号。                                   |
| `MUX`          | 多路选择器                     | 根据控制信号选择某一路输入。例如选择 `rs` 或 `rt` 作为读寄存器编号，选择 `rt` 或 `rd` 作为写寄存器编号。      |
| `MDR`          | 存储器数据寄存器                  | CPU 与主存交换数据时使用。主存读出的数据先进入 MDR；CPU 要写入主存的数据也先放入 MDR。                   |
| `MAR`          | 存储器地址寄存器                  | 保存访问主存的地址，并把地址送到地址总线。                                                 |
**3.主存与外部总线**

|组件|含义|作用|
|---|---|---|
|`主存`|Main Memory|存放程序指令和数据。|
|`Data`|主存数据端|与数据总线相连，用于输入或输出数据。|
|`Addr`|主存地址端|与地址总线相连，接收 CPU 给出的访存地址。|
|`MemR`|主存读控制信号|有效时，主存根据地址总线上的地址，把对应内容送到数据总线。|
|`MemW`|主存写控制信号|有效时，主存把数据总线上的内容写入指定地址。|
|控制总线|Control Bus|传送读、写等控制信号。|
|数据总线|Data Bus|CPU 与主存之间传送数据或指令。|
|地址总线|Address Bus|CPU 向主存发送访问地址。|
**4.寄存器相关控制信号** 

| 控制信号      | 含义         | 作用                                    |
| --------- | ---------- | ------------------------------------- |
| `PCin`    | PC 输入允许    | 允许内部总线上的数据写入 PC。                      |
| `PCout`   | PC 输出允许    | 打开 PC 输出端三态门，使 PC 的内容送到内部总线。          |
| `IRin`    | IR 输入允许    | 允许内部总线上的指令写入 IR。                      |
| `IRout`   | IR 输出允许    | 打开 IR 输出端三态门，使 IR 的内容送到内部总线。          |
| `Xin`     | X 输入允许     | 允许内部总线上的数据写入 X。                       |
| `Zout`    | Z 输出允许     | 打开 Z 输出端三态门，使 ALU 运算结果送到内部总线。         |
| `PSWin`   | PSW 输入允许   | 允许 ALU 产生的状态标志写入 PSW。                 |
| `Rin`     | 寄存器组写允许    | 允许内部总线上的数据写入寄存器组中指定的寄存器。              |
| `Rout`    | 寄存器组读允许    | 打开寄存器组输出端三态门，使选中的寄存器内容送到内部总线。         |
| `MARin`   | MAR 输入允许   | 允许内部总线上的地址写入 MAR。                     |
| `MDRin`   | MDR 内部输入允许 | 允许 CPU 内部总线上的数据写入 MDR。                |
| `MDRout`  | MDR 内部输出允许 | 打开 MDR 到 CPU 内部总线的三态门，使 MDR 内容送到内部总线。 |
| `MDRinE`  | MDR 外部输入允许 | 允许外部数据总线上的数据写入 MDR，常用于主存读。            |
| `MDRoutE` | MDR 外部输出允许 | 打开 MDR 到外部数据总线的三态门，常用于主存写。            |

**5.ALU相关控制信号**

| 控制信号  | 含义     | 作用                                           |
| ----- | ------ | -------------------------------------------- |
| `ADD` | 加法控制信号 | 控制 ALU 执行加法。                                 |
| `SUB` | 减法控制信号 | 控制 ALU 执行减法。                                 |
| `+4`  | 加 4 控制 | 常用于 PC 更新，例如 `PC <- PC + 4`，适用于定长 4 字节指令的机器。 |
**6.寄存器组与 MUX 控制信号**

| 控制信号      | 含义        | 作用                                         |
| --------- | --------- | ------------------------------------------ |
| `Rs / Rt` | 源寄存器选择信号  | 控制上方 MUX，从 `rs` 和 `rt` 中选择一个作为读寄存器编号 `R#`。 |
| `RDst`    | 目的寄存器选择信号 | 控制下方 MUX，从 `rt` 和 `rd` 中选择一个作为写寄存器编号 `W#`。 |
| `rs`      | 源寄存器字段    | 指令中的一个源寄存器编号。                              |
| `rt`      | 源/目的寄存器字段 | 在不同指令中可作为源寄存器或目的寄存器。                       |
| `rd`      | 目的寄存器字段   | 常用于 R 型指令的目的寄存器编号。                         |
**7.三态门的含义和作用**

|项目|说明|
|---|---|
|三态门位置|图中 PC、IR、Z、MDR、寄存器组等部件连接总线处的三角形。|
|三种状态|输出 `0`、输出 `1`、高阻态 `Z`。|
|高阻态含义|相当于该部件暂时与总线断开，不向总线输出数据。|
|为什么需要|因为 CPU 内部是单总线结构，同一时刻只能有一个部件向总线输出数据。|
|如果没有三态门|多个部件可能同时向总线输出不同数据，造成总线冲突。|
**8.PSW 状态标志**

|标志|名称|含义|作用|
|---|---|---|---|
|`OF`|Overflow Flag，溢出标志|有符号数运算结果超出表示范围时置 1。|用于判断有符号运算是否溢出。|
|`CF`|Carry Flag，进位/借位标志|无符号加法产生进位或减法产生借位时置 1。|用于无符号数运算、多字长运算。|
|`SF`|Sign Flag，符号标志|结果最高位为 1 时置 1，通常表示负数。|用于判断运算结果正负。|
|`ZF`|Zero Flag，零标志|运算结果为 0 时置 1。|常用于条件转移，如相等则跳转。|
