## 2.4 浮点数的表示

- 定点数表示的范围有限。
- 实际上，计算机中处理的数不一定都是很小的小数或纯整数。
- 对于需要表示范围更大的实数，可以使用浮点数表示。

### 2.4.1 浮点数的表示形式和表示范围

- 二进制浮点数可以采用类似十进制科学记数法的表示方法。
![[Pasted image 20260702162623.png]]
- 浮点数在机器中的表示通常由两部分组成：
	- 阶码 `E`
	- 尾数 `M`
- 一般形式：`N = r^E × M`
	- `r` 是基数，可以取 `2`、`4`、`8`、`16` 等。
	- `E` 是阶码，用来表示小数点位置。
	- `M` 是尾数，用来表示有效数值部分。
- 浮点数表示范围：
	- 阶码位数影响可表示数的范围。
	- 尾数位数影响可表示数的精度。
- 当浮点数的位数确定后：
	- 合理分配阶码位数和尾数位数，会直接影响浮点数的表示范围和精度。
	- 阶码位数越多，表示范围通常越大。
	- 尾数位数越多，表示精度通常越高。
- 浮点数可能出现：
	- 上溢
	- 下溢
	- 正数区间
	- 负数区间

### 2.4.2 浮点数的规格化

- 浮点数规格化用于对尾数进行规范化处理。
- 规格化的目的：
	- 使浮点数的表示形式唯一。
	- 使尾数的表示精度最高。

- 对于二进制浮点数：
	- ==若尾数的数值部分最高位为 `1`，则为规格化数。==
	- 若非零尾数的数值部分最高位为 `0`，需要左规；若尾数运算产生溢出，即小数点左侧出现有效位，则需要右规。移动尾数时要相应调整阶码。
- 对于基数 `r` 不同的浮点数，规格化形式不同，规格化过程也不同。
	- 当 `r = 2` 时，尾数数值部分最高位为 `1` 的数为规格化数。
		- 左规：尾数数值部分每往左移1位，阶码减1
		- 右规：尾数数值部分每往右移1位，阶码加1
	- 当 `r = 4` 时，尾数数值部分最高两位不全为 `0` 的数为规格化数。
		- 左规：尾数数值部分每往左移2位，阶码减1
		- 右规：尾数数值部分每往右移2位，阶码加1
- 习题中强调：
	- 基数不同，对应的表示范围和精度都会受影响。
	- 一般来说，基数越大，可表示的浮点数范围越大，而相邻两数之间的相对距离也会变化。

### 2.4.3 IEEE 754 浮点数标准

- IEEE 754 单精度浮点数为 32 位。
- 字段划分：

| 字段     | 位数  | 说明                 |
| ------ | --- | ------------------ |
| 符号 `S` | 1位  | `0` 表示正数，`1` 表示负数。 |
| 阶码 `E` | 8位  | 采用[[2.3 定点数的编码#2.3.4 移码\|移码]]表示。            |
| 尾数 `M` | 23位 | 定点小数，采用[[2.3 定点数的编码#2.3.1 原码\|原码]]表示。       |
![[Pasted image 20260701160934.png]]
- IEEE 754 双精度浮点数为 64 位。
- 字段划分：

| 字段     | 位数  | 说明                 |
| ------ | --- | ------------------ |
| 符号 `S` | 1位  | `0` 表示正数，`1` 表示负数。 |
| 阶码 `E` | 11位 | 采用移码表示。            |
| 尾数 `M` | 52位 | 定点小数，采用原码表示。       |
- IEEE 754 单精度中：
	- 阶码采用移码表示。
	- 偏置值为 `127`。
		![[Pasted image 20260701160826.png]]
	- 规格化数的尾数隐含最高位 `1`。
- IEEE 754 单精度浮点数分类：

| 阶码 E          | 尾数 M | 表示          |
| ------------- | ---- | ----------- |
| 全 0           | `0`  | `+0` 或 `-0` |
| 全 0           | 非 0  | 非规格化数       |
| `1 ≤ E ≤ 254` | 任意   | 规格化数        |
| 全 1           | `0`  | 正无穷或负无穷     |
| 全 1           | 非 0  | `NaN`       |
![[Pasted image 20260701161314.png]]
- ==非规格化数可用于处理阶码下溢，使得出现比最小规格化数还小的数时程序也能继续进行下去==。
- 规格化数真值：`(-1)^S × 2^(E-127) × 1.M`

- 浮点数和机器数之间转换的一般思路：
	1. 将真值转为二进制。
	2. 写成规格化形式。
	3. 确定符号位 `S`。
	4. 根据阶码偏置值确定 `E`。
	5. 按尾数部分填写 `M`。
