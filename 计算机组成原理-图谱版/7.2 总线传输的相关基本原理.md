## 7.2 总线传输的相关基本原理

### 7.2.1 总线传输过程和总线事务
- 一次总线传输通常包括 4 个阶段：

| 阶段 | 作用 |
| --- | --- |
| 申请 | 主设备申请总线控制权。 |
| 寻址 | 主设备给出要访问的地址，并指出传输方向或操作类型。 |
| 传输 | 主设备和从设备之间传送数据。 |
| 结束 | 释放总线，结束本次传输。 |
![[Pasted image 20260702145949.png]]

- 申请阶段：
	- 主设备向总线控制器发出总线请求信号。
	- 总线控制器根据仲裁规则决定是否授予控制权。
- 寻址阶段：
	- 主设备把地址送到地址总线。
	- 通过控制信号指出读、写或其他操作。
- 传输阶段：
	- 若为读操作，从设备把数据送到总线，主设备接收。
	- 若为写操作，主设备把数据送到总线，从设备接收。
- 结束阶段：
	- 主设备停止占用总线。
	- 总线回到空闲状态或开始下一次传输。

- 总线事务是总线上的一对主/从设备之间完成一次信息交换的过程。
- 常见总线事务类型：
	- 存储器读
	- 存储器写
	- I/O 读
	- I/O 写
	- [[6.5 异常与中断#6.5 异常与中断|中断]]响应
	- [[8.4 I O控制方式#8.4.4 DMA方式|DMA]] 响应
- 突发传输：
	- 也称 Burst Mode。
	- 一次寻址后连续进行多次数据传输。
	- 适合连续地址上的数据块传输。

### 7.2.2 总线仲裁
- 总线仲裁用于解决多个主设备同时请求使用总线时，谁先获得总线控制权的问题。
- 完成仲裁的部件称为==总线仲裁器==。

- 总线仲裁方式可以分为：

| 类型    | 思路                                             |
| ----- | ---------------------------------------------- |
| 集中式仲裁 | 将仲裁逻辑集中在一个部件中，通常放在总线控制器或 [[1.3 计算机硬件\|CPU]] 中。 |
| 分布式仲裁 | 将仲裁逻辑分散在各主设备中。                                 |
![[Pasted image 20260702150144.png]]
**1.集中式仲裁**

| 方法 | 特点 |
| --- | --- |
| 链式查询方式 | 总线同意信号按设备顺序串行传递，离仲裁器近的设备优先级高。 |
| 计数器定时查询方式 | 仲裁器用计数器依次查询设备，计数起点可以改变。 |
| 独立请求方式 | 每个主设备都有独立的请求线和授权线，响应速度快但控制线数量多。 |
![[Pasted image 20260702150157.png]]
![[Pasted image 20260702150213.png]]
![[Pasted image 20260702150222.png]]
- 链式查询方式：
	- 控制逻辑简单。
	- 优先级固定，靠近仲裁器的设备优先级高。
	- 若链路中某设备故障，可能影响后续设备。
- 计数器定时查询方式：
	- 可以通过改变计数起点调整优先级。
	- 所需控制线少于独立请求方式。
- 独立请求方式：
	- 每个主设备独立申请。
	- 仲裁速度快，优先级可灵活设置。
	- 需要的控制线数量较多。

**2.分布式仲裁**

| 方法 | 特点 |
| --- | --- |
| 自举分散方式 | 各主设备按一定优先级规则自行判断是否获得总线。 |
| 并行竞争方式 | 多个主设备并行送出仲裁号，按仲裁号大小确定优先级。 |
| 冲突检测分散方式 | 通过检测冲突来决定谁继续占用总线。 |

### 7.2.3 总线定时
- 总线定时用于规定总线传输过程中各信号在时间上的配合关系。
![[Pasted image 20260702150415.png]]

| 定时方式 | 特点 |
| --- | --- |
| 同步通信 | 所有设备在统一时钟控制下完成总线传输。 |
| 异步通信 | 没有统一时钟，通过请求和确认信号握手。 |
| 半同步通信 | 在同步通信基础上增加等待信号。 |
| 分离事务通信 | 将一个总线事务拆成两个子事务，中间释放总线。 |
![[Pasted image 20260702150425.png]]
![[Pasted image 20260702150443.png]]
![[Pasted image 20260702150452.png]]
![[Pasted image 20260702150524.png]]
- 同步通信：
	- 优点是时序规则明确、控制简单。
	- 缺点是总线周期通常取决于最慢设备。
- 异步通信：
	- 请求信号和确认信号完成握手。
	- 可以分为非互锁、半互锁、全互锁方式。
	- 适合速度差异较大的设备。
- 半同步通信：
	- 保留统一时钟。
	- 从设备来不及完成操作时，可以通过等待信号 `WAIT` 延长传输过程。
- 分离事务通信：
	- 从设备准备数据期间不占用总线。
	- 总线可以被其他事务使用。
	- 能提升总线利用率，但控制更复杂。
