## 2.5 C语言中的数据类型及转换

- 以 C 语言中的数据类型为例说明机器数解释规则。
- `char` 变量为 8 位。
	- `char` 的取值范围：`-128 ~ 127`。
	- `unsigned char` 的取值范围：`0 ~ 255`。

- 整型数据之间转换：
	- `char`、`short`、`int`、`long` 这些整型数据的表示范围不同。
	- 转换后可能发生精度损失。
	- 转换时会根据目标类型的位宽和有无符号属性，对相应的低位比特进行保留、扩展或截断；若目标类型无法表示原值，转换后的数值可能发生变化。

| 转换情况              | 规则            |
| ----------------- | ------------- |
| 相同字长之间转换          | 机器码不变，解释方式改变。 |
| 小字长转大字长，原数据为无符号类型 | 进行 `0` 扩展。    |
| 小字长转大字长，原数据为有符号类型 | 进行符号扩展。       |
| 大字长转小字长           | 高位被截断。        |

- `int`、`float`、`double` 之间也可以进行强制类型转换。
	- `int` 通常采用[[2.3 定点数的编码#2.3.2 补码|补码]]表示。
	- `float` 和 `double` 采用[[2.4 浮点数的表示#2.4 浮点数的表示|浮点数]]表示。
	- 转换过程中，编译器只能保证转换后数值尽量相等，大多数情况下只是近似值。
- 转换方向包括：
	- `float -> double`
	- `double -> float`
	- `float/double -> int`
	- `int -> float`
	- `int -> double`
