## 7.5 常用总线
- 按总线所在位置列出了常见总线。

| 类别                                      | 常见总线                                                             |
| --------------------------------------- | ---------------------------------------------------------------- |
| 片内总线                                    | AMBA、Wishbone                                                    |
| [[7.4 系统总线的结构#7.4 系统总线的结构\|系统总线]] | ISA/EISA、MCA、VESA、PCI、FSB、HT、QPI、DMI 等                         |
| I/O 总线                                  | AGP、PCIe、LPC、SPI、I2C/SMBus、ATA/IDE、SATA、SCSI、SAS、Fiber Channel 等 |
| 外部总线                                    | RS-232-C、RS-485、IEEE-488、USB、IEEE 1394、Thunderbolt、InfiniBand 等  |

- 常用总线名称容易混淆，需要结合所在位置理解：
	- CRT、USB、EISA 等属于不同类别。
	- [[1.7 计算机系统的性能指标#1.7.2 与运算速度相关的性能指标|CPI]] 表示每条指令平均周期数，不是总线名称。
- USB 总线的特点：
	- 通过个人用户应用广泛。
	- 支持热插拔。
	- 设备通过 USB Hub 分层连接。
	- 一个 USB Hub 可连接多个下游端口。
