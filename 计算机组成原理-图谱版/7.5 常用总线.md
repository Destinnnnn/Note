## 7.5 常用总线
- 总线和互连可按所在位置或主要用途分类，但不同教材和不同计算机平台的分类口径并不完全一致。下表列出典型用途，而不是互斥的绝对分类。

| 典型用途或位置 | 常见总线或互连 |
| --- | --- |
| 片内互连 | AMBA、Wishbone 等 |
| [[7.4 系统总线的结构#7.4 系统总线的结构\|处理器、内存或芯片间互连]] | FSB、HT、QPI、DMI、内存总线等 |
| 局部或扩展互连 | ISA/EISA、MCA、VESA、PCI、AGP、PCIe、LPC 等 |
| 存储或低速设备互连 | SPI、I2C/SMBus、ATA/IDE、SATA、SCSI、SAS、Fibre Channel 等 |
| 外部设备或通信互连 | RS-232-C、RS-485、IEEE-488、USB、IEEE 1394、Thunderbolt、InfiniBand 等 |

- 同一种互连在不同平台中可能承担不同角色。例如 PCIe 既常作为 I/O 扩展互连，也可以用于芯片间或系统级互连，因此应结合具体体系结构判断。
- [[1.7 计算机系统的性能指标#1.7.2 与运算速度相关的性能指标|CPI]] 表示每条指令平均周期数，不是总线名称。
- USB 总线的特点：
	- 在个人计算机和消费电子设备中应用广泛。
	- 支持热插拔。
	- 设备通过 USB Hub 分层连接。
	- 一个 USB Hub 可连接多个下游端口。
