## 1.5 计算机系统的层次结构

- 计算机是一个非常复杂的系统。
- 为了简化对计算机系统的研究和实现，可以采用分层思想，将计算机系统划分成一个层次结构。
- 分层思想：
	- 系统中的每一层都向其上层提供一个简洁、抽象的接口。
	- 每一层的实现细节对其上层而言都是透明的。
	- 计算机解决问题的过程就是层层转换的过程。

- 计算机系统层次：

| 层次  | 名称                                 | 说明                                         |
| --- | ---------------------------------- | ------------------------------------------ |
| 第1层 | 逻辑电路层                              | 计算机硬件系统的底层，由逻辑门、寄存器等逻辑电路组成。                |
| 第2层 | 微程序层                               | 将一条机器指令编写成一个微程序，每个微程序包含若干微指令，每条微指令对应一组微操作。 |
| 第3层 | [[指令集架构 (ISA) 核心规定|指令集体系结构层 ISA]] | 定义计算机可执行机器指令的集合，并规定各种指令格式和功能。              |
| 第4层 | [[1.4 计算机软件#1.4 计算机软件|操作系统]]层                              | 对计算机硬件资源和软件资源进行统一管理和调度，提高系统使用效率，方便用户使用。    |
| 第5层 | 汇编语言层                              | 使用汇编语言编写程序，由汇编程序翻译成机器语言程序。                 |
| 第6层 | 高级语言层                              | 使用与机器无关的高级语言编写程序，再翻译到低层执行。                 |

- 最终用户通常面对的是各类应用程序。
- 程序员主要面对高级语言层和汇编语言层。
- 系统程序员和硬件工程师会更多接触操作系统层、ISA、微程序层和逻辑电路层。
- 软件和硬件具有逻辑功能等价性：
	- 对于一类特定的计算过程，既可以选择用软件编程实现，也可以选择用硬件电路实现。
	- 软件实现灵活、成本低、便于修改。
	- 硬件实现速度快、响应时间短，但开发和制造更复杂。
