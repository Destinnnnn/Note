## 4.1 存储器概述

- 现代计算机以==存储器为中心==。
- 存储器是计算机中存放指令和数据的主要部件。
- 存储系统的关键目标包括：
	- 存储容量大。
	- 存取速度快。
	- 成本低。
- 为了兼顾容量、速度和成本，计算机采用层次化的存储系统。

### 4.1.1 存储器分类

| 分类依据    | 类型             | 中的要点                         |
| ------- | -------------- | ---------------------------- |
| 存储介质    | 磁存储器           | 以磁性材料作为存储介质，如磁带、磁盘。          |
| 存储介质    | 光存储器           | 利用光学特性读写数据，如 CD-ROM、DVD-ROM。 |
| 存储介质    | 半导体存储器         | 利用半导体器件存储信息，如内存、固态硬盘中的存储芯片。  |
| 存取方式    | 随机存储器          | 可按地址随机访问任意存储单元。              |
| 存取方式    | 顺序存储器          | 只能按某种顺序依次访问。                 |
| 存取方式    | 直接存储器          | 可先定位到大致区域，再顺序查找目标数据。         |
| 可改写性    | 读写存储器          | 存储内容可以读出，也可以写入。              |
| 可改写性    | 只读存储器          | 存储内容通常只能读出，不能随意写入。           |
| 可保存性    | 易失性存储器         | 断电后信息丢失。                     |
| 可保存性    | 非易失性存储器        | 断电后信息仍能保存。                   |
| 功能和存取速度 | 寄存器、高速缓存、主存、辅存 | 越靠近CPU，速度越快、容量越小、成本越高。       |

- CPU 与主存之间通常还有==高速缓存 [[4.7 高速缓冲存储器cache#4.7 高速缓冲存储器cache|cache]]==，用于缓解 CPU 与主存之间的速度矛盾。

### 4.1.2 存储器性能指标和存储系统层次结构

#### 存储容量

- 存储容量是指存储器可以存储的==二进制信息的总量==。
- [[4.1 存储器概述#4.1.3 主存的基本结构|主存]]容量与以下因素有关：
	- `MAR` 的位数：决定可寻址存储单元的数量。
	- `MDR` 的位数：通常与存储字长相等。
- 若 `MAR` 为 `n` 位，则最多可寻址 `2^n` 个存储单元。

#### 存取速度

| 指标 | 含义 |
| --- | --- |
| 存取时间 | 启动一次存储器操作到完成该操作所经历的时间。读出时间和写入时间可能不同。 |
| 存取周期 | 连续两次访问存储器操作之间所需的最小时间间隔。通常大于存取时间。 |
| 存储器带宽 | 单位时间内存储器能够传送的信息量。 |

#### 存储系统层次结构

| 层次   | 图中的典型速度/容量关系    |
| ---- | --------------- |
| 寄存器  | 速度最快，容量最小，成本最高。 |
| 高速缓存 | 位于  CPU 和 主存之间。 |
| 主存   | 直接与 CPU 交换信息。   |
| 辅存   | 容量大、成本低、速度慢。    |

- 上层存储器可以作为下层存储器的缓存，把经常使用的数据副本调到上层。
- 这样可以利用较低成本构建一个容量大、速度接近上层存储器的存储系统。



### 4.1.3 主存的基本结构

- 主存是机器指令可直接操作的存储器，需要基于==主存地址==进行随机访问。
- 主存的基本结构包括：
	- 存储体：由大量存储单元构成。
	- 地址译码器：根据地址选择对应的存储单元。
	- `MAR`：保存访问主存的地址。
	- `MDR`：保存从主存读出或将要写入主存的数据。
	- 地址[[7.1 总线概述#7.1 总线概述|总线]]、数据总线、控制总线。
- `MAR` 的位数决定了可寻址存储单元的数量。
- `MDR` 的位数通常与存储字长相等。
- 随着集成技术发展，图中说明 `MAR` 和 `MDR` 被集成到了 CPU 中。



### 4.1.4 用于地址译码的译码结构

| 译码结构  | 特点                               |
| ----- | -------------------------------- |
| 单译码结构 | 只使用一个地址译码器，地址译码输出线数量随地址线位数指数增长。  |
| 双译码结构 | 把地址分成行地址和列地址，用行译码器与列译码器共同选中存储单元。 |

- 若有 `n` 条地址线：
	- 单译码结构需要 `2^n` 条译码输出线。
	- 双译码结构可分成 `n/2` 条行地址线和 `n/2` 条列地址线，分别产生 `2^(n/2)` 条行选择线和 `2^(n/2)` 条列选择线。
- 双译码结构适合大容量存储器芯片，可以显著减少译码输出线数量。

### 4.1.5 主存中数据的存放

#### 地址访问模式

- 主存通常按==字节地址==进行编址。
- 字节地址是指主存中某个字节单元的地址。
- 半字地址、字地址等可以由字节地址推得。
- 图中说明，[[1.3 计算机硬件#1.3 计算机硬件|CPU]] 执行指令时仍可以按字节、半字、字等不同长度访问数据。
![[Pasted image 20260701170416.png]]
#### 大端和小端方式

| 方式 | 存放规则 |
| --- | --- |
| 大端方式 | 数据的高字节保存在主存的低地址中，低字节保存在高地址中。 |
| 小端方式 | 数据的低字节保存在主存的低地址中，高字节保存在高地址中。 |

![[Pasted image 20260701170424.png]]

#### 数据的边界对齐

- 字节数据不需要边界对齐。
- 半字数据的起始字节地址低位应为 `0`。
- 单字数据的起始字节地址低两位应为 `00`。
- 边界对齐会使数据读取更方便，但可能在结构体中产生空闲字节。
