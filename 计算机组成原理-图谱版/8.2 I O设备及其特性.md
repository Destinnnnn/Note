## 8.2 I/O设备及其特性
- I/O 设备是计算机与人或其他系统进行数据交互的装置，也称为外部设备。

- I/O 设备可以分为：

| 类型 | 作用 |
| --- | --- |
| 输入设备 | 将数据、文字、图片、音频、视频等转换成计算机可识别的二进制信息。 |
| 输出设备 | 将计算机处理结果转换成数字、文字、图像、声音、视频等形式。 |

- I/O 设备分类角度：

| 分类角度 | 类型 |
| --- | --- |
| 结构差异 | 机械式、电子式 |
| 信号差异 | 数字信号、模拟信号 |
| 性能差异 | 慢速、中速、高速 |
| 访问差异 | 顺序访问、随机访问 |

- I/O 设备的主要特性：

| 特性 | 含义 |
| --- | --- |
| 异步性 | I/O 设备与 [[1.3 计算机硬件#1.3 计算机硬件|CPU]] 的工作节奏不同，I/O 操作常常与 CPU 执行异步发生。 |
| 实时性 | 某些设备对数据输入输出时机有严格要求。 |
| 独立性 | 通过接口和驱动程序屏蔽设备差异，使 CPU 可以用相对统一的方式访问设备。 |

- I/O 设备速度差异较大：
	- 慢速设备若处理不当，会使 CPU 长时间等待。
	- 高速设备若处理不及时，可能导致数据丢失。
