## 2.3 定点数的编码

- 定点数的小数点位置固定。
- 按以下编码方式介绍定点数：
	- [[2.3 定点数的编码#2.3.1 原码|原码]]
	- [[2.3 定点数的编码#2.3.2 补码|补码]]
	- [[2.3 定点数的编码#2.3.3 反码|反码]]
	- [[2.3 定点数的编码#2.3.4 移码|移码]]

### 2.3.1 原码

- 原码由两部分组成：
	- 符号位
		- `0` 表示正数。
		- `1` 表示负数。
	- 数值位（二进制）
	![[Pasted image 20260701155409.png]]
- 对定点整数：
	- 正数的原码：符号位为 `0`，数值位就是其本身。
	- 负数的原码：符号位为 `1`，数值位是真值绝对值。
- 对定点小数：
	- 正数仍用符号位 `0`。
	- 负数仍用符号位 `1`。
	- 数值位表示小数部分的绝对值。
	![[Pasted image 20260701155616.png]]
- 原码的特点：
	- 优点：表示方法简单直观。
	- 缺点：
		- ==真值 `0` 在原码中有两种不同表示==。
		- 符号位不能直接参与运算。
- *特别说明：原码在计算机中目前仅用于表示[[2.4 浮点数的表示#2.4 浮点数的表示|浮点数]]的尾码。*

### 2.3.2 补码

- 补码概念先从“模”引入。
- 模（或称模数）是一个数值计量系统的==计量范围==，记作 `mod M`。
	- 只要确定了“模”，就可以找到与负数等价的正数来代替该负数。
	- 超过计量范围的整数部分会自动舍弃。

- 补数的特点：
	- 一个负数可由它的正补数来替代。
	- 这个正补数可以用==模数加上负数本身==求得。
	- 一个正数和一个负数互为补数时，它们绝对值之和为模数。
	- 正数的补数就是正数本身。
- 将补数概念应用到计算机内部，就得到了补码这种机器码。
- 补码规则：
	- 正数补码：符号位为 `0`，数值位就是它本身。
	- 负数补码：符号位为 `1`，数值位等于模数加上该负数本身。
- 定点整数补码：
	- 最高位为符号位。
	- 模数是最高位对应位权的 2 倍。
- 定点小数补码：
	- 最高位为符号位。
	- 模数为 `2`。
- 补码的优点：
	- 可以把减法运算转化为加法运算。
	- 正数和负数可以统一参与加法。
	- ==`0` 只有一种表示。==
- 现代计算机中多采用 [[2.4 浮点数的表示#2.4.3 IEEE 754 浮点数标准|IEEE 754]] 标准表示浮点数，而其中的定点小数采用原码表示，因此通常不会涉及定点小数的补码表示。

### 2.3.3 反码

- 反码通常用作==原码转补码==或==补码求原码==的中间过渡。

- 反码规则：
	- 正数反码：符号位为 `0`，数值位就是它本身。
	- 负数反码：符号位为 `1`，数值位是其真值数值位按位取反。
- 定点整数反码：
	- 正数按原值表示。
	- 负数保留符号位 `1`，数值位取反。
- 定点小数反码：
	- 正数按原值表示。
	- 负数保留符号位 `1`，数值位取反。
- 反码的特点：
	- 符号位可以参与运算。
	- 真值 `0` 在反码中仍有两种不同表示。
	- 运算时可能产生循环进位，需要把最高位进位加回最低位。

### 2.3.4 移码

- 移码是在真值上加一个常数 `2^n`。
- 在数轴上，移码所表示的范围相当于真值在数轴上的范围向正方向移动 `2^n` 个单元。
- ==移码只用于定点整数的表示==。

- 移码定义：`[x]_移 = x + 2^n`

- 移码的特点：
	- ==真值 `0` 在移码中只有一种表示。==
	- 保留了原有数值的大小顺序，可以直接比较大小。
	- 最小真值的移码为全 `0`。
	- 最大真值的移码为全 `1`。
	- 这种表示方式比较符合人们的习惯。
- 移码常用于浮点数阶码部分的表示。

### 2.3.5 原码、补码、反码、移码之间的转换

- 图中给出原码、反码、补码、移码之间的转换关系。

  ![[Pasted image 20260701155915.png]]

- 真值为正数时：
	- 原码符号位为 `0`。
	- 原码、反码、补码的数值位相同。
	- 移码与补码相比，符号位相反。
- 真值为负数时：
	1. 原码：符号位为 `1`，数值位为绝对值。
	2. 反码：在原码基础上，==数值位按位取反==。
	3. 补码：在反码基础上，==末位加 1==。
	4. 移码：在补码基础上，==符号位取反==。
- 补码求相反数：
	- 全部按位取反。
	- 末位加 `1`。
- 还给出“扫描法”：
	- 从右到左扫描。
	- 右边第一个 `1` 及其右边保持不变。
	- 第一个 `1` 左边的各位取反。
