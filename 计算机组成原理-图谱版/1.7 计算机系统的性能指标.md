## 1.7 计算机系统的性能指标

- 计算机系统的性能指标用于衡量计算机系统在各种操作和任务中的工作效率、执行速度以及处理能力。
- 性能指标也可以辅助人们评估计算机系统的整体表现，并了解系统在不同方面的优劣和限制。
- ==计算机系统性能与硬件和软件都有关系==。

| 方面 | 对性能的影响 |
| --- | --- |
| 硬件 | 构建计算机系统的物理组件，例如 [[1.3 计算机硬件#1.3 计算机硬件\|CPU]]、内存、外部设备等；硬件决定系统的计算能力、数据传输速率和存储容量。 |
| 软件 | 用于控制、管理、应用计算机系统的各类系统软件和应用软件；软件优化可以提高计算机系统性能。 |

- 硬件影响示例：
	- CPU 的时钟频率决定每秒钟包含的时钟周期数；CPU 每秒钟可以执行的指令数量还取决于 CPI。
	- 内存带宽会影响数据的读写速率。
- 软件影响示例：
	- [[1.4 计算机软件#1.4 计算机软件|操作系统]]调度算法会影响多任务处理效率。
	- 编译器优化可以减少 CPU 执行的负担。
	- 并行计算可以更好地利用多核处理器，提高吞吐量。

### 1.7.1 基本性能指标

- 基本性能指标包括：
	- 机器字长
	- [[4.1 存储器概述#4.1.3 主存的基本结构|主存]]容量
	- 吞吐量
	- 响应时间

| 指标 | 含义 |
| --- | --- |
| 机器字长 | CPU 一次能够处理的二进制数据的位数，也是能够表示二进制数据的比特数量。 |
| 主存容量 | 主存储器能够存储的最大信息量。 |
| 吞吐量 | 计算机系统在单位时间内能够处理的信息量。 |
| 响应时间 | 从向计算机系统提交作业开始，到系统完成作业为止所需要的时间。 |

- 机器字长：
	- 与 CPU 内部用于整数运算的 [[1.6 计算机的基本工作原理#1.6 计算机的基本工作原理|ALU]] 位数以及通用寄存器宽度相等。
	- 字长越长，数的表示范围越大，精度也越高。
- 主存容量：
	- 假设主存包含 `N` 个存储单元，每个存储单元可存储 `M` 个二进制位。
	- 主存容量 = `N × M` 位。
	- 给出的单位关系：

| 单位 | 换算 |
| --- | --- |
| 比特 bit | 基本单位。 |
| 字节 B | `1B = 8bit` |
| 千字节 KB | `KB = 2^10 B` |
| 兆字节 MB | `MB = 2^20 B` |
| 吉字节 GB | `GB = 2^30 B` |
| 太字节 TB | `TB = 2^40 B` |

- 响应时间中包含：
	- CPU 执行时间。
	- 系统 CPU 时间。
	- 其他时间。

### 1.7.2 与运算速度相关的性能指标

- 与运算速度相关的性能指标包括：
	- CPU 时钟频率和时钟周期
	- CPI
	- CPU 执行时间
	- IPC
	- MIPS
	- MFLOPS

- CPU 时钟周期：
	- CPU 时钟信号是基本的电信号。
	- CPU 时钟周期是 CPU 时钟频率的倒数，基本单位为秒。

| 频率单位 | 换算 |
| --- | --- |
| Hz | 基本单位。 |
| kHz | `kHz = 10^3 Hz` |
| MHz | `MHz = 10^6 Hz` |
| GHz | `GHz = 10^9 Hz` |

| 时间单位 | 换算 |
| --- | --- |
| s | 基本单位。 |
| ms | `ms = 10^-3 s` |
| us | `us = 10^-6 s` |
| ns | `ns = 10^-9 s` |

- CPI：
	- CPI 表示==执行每条指令所需的平均时钟周期数==。
	- 如果程序中不同类型指令的 CPI 不同，可以按各类指令出现比例求加权平均 CPI。
	- `CPI = Σ(CPI_i × P_i)`

- CPU 执行时间：
	- `CPU执行时间 = (CPI × 程序所包含的指令条数) × 时钟周期`
	- `CPU执行时间 = (CPI × 程序所包含的指令条数) / 时钟频率`

- IPC：
	- IPC 表示==每个时钟周期能够执行的指令数==。
	- 对同一工作负载和统计区间，IPC 是 CPI 的倒数，即 `IPC = 1 / CPI`。
- MIPS：
	- MIPS 的意思是==每秒执行多少百万条指令==。
	- `MIPS = (时钟频率 / CPI) / 10^6`
	- ==用 MIPS 对不同计算机进行性能比较有时是不准确的。==
		- 不同机器的指令集不同，一条指令的功能也可能不同。
		- 不同机器的 CPI 和时钟周期可能不同。
- MFLOPS：
	- MFLOPS 的意思是==每秒执行多少百万次浮点运算==。
