## 4.4 只读存储器ROM简介

- 只读存储器 `ROM` 只能从其中读出信息，而不能向其随意写入信息。
- `ROM` 是==非易失性存储器==，断电后信息不会丢失。
- 数据被写入 `ROM` 后，即使断电，保存的信息也不会丢失。

| 类型 | 中的要点 |
| --- | --- |
| `MROM` | 掩模式只读存储器，内容由厂家在生产过程中写入，用户不能改写。 |
| `PROM` | 可编程只读存储器，用户可用编程器写入一次，之后不能再改写。 |
| `EPROM` | 可多次写入，但重写前需要擦除原内容，图中提到紫外线擦除窗口。 |
| `EEPROM` | 可多次写入，可用电信号擦除和改写。 |
| 闪存 | 逻辑结构与 `EEPROM` 相似，但按块擦除，常用于大容量外存设备。 |

- [[1.6 计算机的基本工作原理#1.6 计算机的基本工作原理|PC]] 中常见的半导体存储器包括：
	- BIOS 芯片。
	- 固态硬盘中的 NAND 型闪存芯片。
	- CPU 内部的 [[4.7 高速缓冲存储器cache#4.7 高速缓冲存储器cache|cache]]。
	- 内存条中的 DRAM 芯片。
- 图中把[[4.1 存储器概述#4.1.3 主存的基本结构|主存]]分成 `RAM` 和 `ROM` 两部分：
	- `RAM` 用于存放 [[1.3 计算机硬件#1.3 计算机硬件|CPU]] 执行的指令和用户数据。
	- `ROM` 用于存放启动时执行的固件程序。
