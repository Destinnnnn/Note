## 1.6 计算机的基本工作原理

- 运算器中出现的寄存器和部件：

| 部件  | 图中的作用                     |
| --- | ------------------------- |
| [[1.6 计算机的基本工作原理#1.6 计算机的基本工作原理|ALU]] | 执行加、减、乘、除等运算。             |
| ACC | 累加器，保存参与运算或运算结果。          |
| MQ  | 乘商寄存器，在乘法、除法中保存乘数、乘积低位或商。 |
| X   | 操作数寄存器，保存加数、减数、被乘数或除数。    |

- 不同运算时寄存器的大致配合：

| 运算 | ACC | MQ | X |
| --- | --- | --- | --- |
| 加 | 被加数、和 |  | 加数 |
| 减 | 被减数、差 |  | 减数 |
| 乘 | 乘积高位 | 乘数、乘积低位 | 被乘数 |
| 除 | 被除数、余数 | 商 | 除数 |

- 存储器由许多存储单元组成。
	- 每个存储单元由若干存储元件组成。
	- 每个存储元件可以存储一位二进制数 `0` 或 `1`。
	- 一个存储单元中可存储的一串二进制信息称为==存储字==。
	- 一个存储字的二进制位数称为==存储字长==。
- 每个存储单元都对应一个编号，称为存储单元地址。
- 与存储器配合的寄存器：

| 寄存器 | 作用 |
| --- | --- |
| MAR | 存储器地址寄存器，用来存放被访问的存储单元地址。 |
| MDR | 存储器数据寄存器，用来存放从存储单元取出的数据，或将要写入存储单元的数据。 |

- ==MAR 的位数决定了可寻址的存储单元数量==。
- ==MDR 的位数与存储字长相等==。

- 控制器的主要部件：
	- CU
	- [[1.6 计算机的基本工作原理#1.6 计算机的基本工作原理|PC]]
	- IR
- 图中说明：
	- CU 用来分析当前指令所需完成的操作，并发出各种微操作命令序列。
	- PC 用来保存下一条要执行指令的地址。
	- IR 用来保存当前正在执行的指令。
- 计算机的基本工作过程：
	1. 初始化时，`PC = 0`，指向内存中编号为 0 的存储单元。
	2. 根据 PC 中的地址取出第一条机器指令。
	3. 指令送入 IR 后，由 CU 分析并产生控制信号。
	4. 执行完成后，PC 指向下一条指令。
	5. 计算机按指令序列不断重复取指、分析、执行的过程。
