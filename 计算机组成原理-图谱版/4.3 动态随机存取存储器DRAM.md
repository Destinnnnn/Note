## 4.3 动态随机存取存储器DRAM

### 4.3.1 存储元及其扩展

- 动态随机存取存储器 `DRAM` 的存储元通常由 `1` 个 MOS 管和 `1` 个电容构成。
- 电容上的电荷会逐渐泄漏，数据只能保存较短时间。
- 因此 `DRAM` 必须定期采用类似“读操作”的方式给电容补充电荷，称为==刷新==。
- `DRAM` 得名的原因就是：需要动态刷新。
- 说明：
	- 读出一个存储元会读取所选行中所有存储元的信息。
	- 电容被读取后，其电荷状态会被破坏。
	- 读出后必须立即进行重写/恢复。
- `DRAM` 存储元数量少、集成度高、成本低，适合做大容量[[4.1 存储器概述#4.1.3 主存的基本结构|主存]]。

### 4.3.2 存储器的动态刷新

- 从数据存入 `DRAM` 开始，到数据丢失之前为止的这段时间称为==最大刷新周期==。
- 不同生产工艺下，常见最大刷新周期包括 `2ms`、`4ms`、`8ms` 等。
- `DRAM` 按行刷新，为了缩短刷新周期，可以减少存储阵列的行数、增加列数。
- 刷新操作期间，不能响应 [[1.3 计算机硬件#1.3 计算机硬件|CPU]] 的访存请求，可能产生==死区==。

| 刷新方式 | 中的特点 |
| --- | --- |
| 集中刷新 | 在刷新周期内集中安排刷新操作，死区集中出现。 |
| 分散刷新 | 把刷新操作分散插入到各次读写周期之间，不存在集中的死区，但系统速度受影响。 |
| 异步刷新 | 结合集中刷新和分散刷新，把刷新周期分成若干时间间隔，在每个间隔内刷新一行。 |

### 4.3.3 存储器芯片实例和DRAM发展

- 把 `128 × 128` 的存储阵列作为芯片内部结构示例：
	- `128 × 128 = 2^7 × 2^7 = 2^14 = 16K`。
	- 每次输出 `1` 位。
- `DRAM` 芯片采用行地址和列地址分时送入的方式，以减少地址引脚数量。
	- `RAS`：行地址选通信号。
	- `CAS`：列地址选通信号。
- `DRAM` 的发展方向与 CPU 访问速度关系密切。

| 类型 | 图中的要点 |
| --- | --- |
| 异步 DRAM | 与 CPU 的时钟不同步。 |
| SDRAM | 时钟信号与[[7.4 系统总线的结构#7.4 系统总线的结构|系统总线]]频率同步，可按固定时序进行连续数据传输。 |
| DDR SDRAM | 在时钟周期的上升沿和下降沿都能进行数据传输。 |
