## 5.4 指令的操作类型

- 指令的基本操作类型包括：

| 类型 | 中的说明 |
| --- | --- |
| 数据传送指令 | 在寄存器、[[4.1 存储器概述#4.1.3 主存的基本结构\|主存]]、I/O 端口等位置之间传送数据。 |
| 算术和逻辑运算指令 | 用于完成 [[1.3 计算机硬件#1.3 计算机硬件\|CPU]] 所实现的基本运算功能，如加、减、逻辑运算等。 |
| 移位操作指令 | 用于完成逻辑移位、算术移位、循环移位等操作。 |
| 程序控制指令 | 用于改变程序执行顺序，如转移指令、子程序调用与返回指令。 |
| 输入输出指令 | 用于进行外设输入输出操作。 |
| 其他指令 | 包括空操作、停机、等待等特殊控制类指令。 |

- 算术和逻辑运算指令会影响 CPU 中的[[3.6 运算器#常见状态标志位|状态标志位]]
- 转移指令可分为无条件转移和条件转移。
- 子程序调用和返回指令用于完成子程序之间的转入与返回。
