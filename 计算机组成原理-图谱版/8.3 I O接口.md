## 8.3 I/O接口
- I/O 接口位于[[7.4 系统总线的结构#7.4 系统总线的结构|系统总线]]和 I/O 设备之间，用于完成 CPU、主存和外部设备之间的信息交换。

### I/O接口的功能

| 功能 | 说明 |
| --- | --- |
| 设备寻址 | 根据地址选择指定 I/O 设备或接口寄存器。 |
| 设备控制 | 接收 [[1.3 计算机硬件#1.3 计算机硬件|CPU]] 发出的控制命令并控制设备动作。 |
| 状态检测 | 向 CPU 提供设备忙、就绪、出错等状态。 |
| 数据交互 | 完成 CPU 与 I/O 设备之间的数据传送。 |
| 数据缓冲 | 缓解 CPU、[[7.1 总线概述#7.1 总线概述|总线]]和 I/O 设备之间速度不匹配。 |
| 格式转换 | 在设备信号格式和 CPU/总线数据格式之间转换。 |
| [[6.5 异常与中断#6.5 异常与中断|中断]]、时序控制、错误检测 | 处理中断请求、时序配合和数据错误等问题。 |

### I/O接口的结构

| 寄存器 | 作用 |
| --- | --- |
| 数据寄存器 | 保存 CPU 与 I/O 设备之间传送的数据。 |
| 设备控制寄存器 | 保存 CPU 送来的控制命令。 |
| 设备状态寄存器 | 保存设备状态信息。 |

- 设备控制寄存器和设备状态寄存器有时可以合称为==设备控制/状态寄存器==。
- I/O 接口可以看作一种主设备与 I/O 设备之间的中间部件。
	- 一侧连接[[7.4 系统总线的结构#7.4 系统总线的结构|系统总线]]。
	- 另一侧连接具体 I/O 设备。

### I/O接口的编址

| 编址方式 | 特点 |
| --- | --- |
| 统一编址 | I/O 端口与[[4.1 存储器概述#4.1.3 主存的基本结构|主存]]单元统一编址，使用同一套访存指令访问。 |
| 独立编址 | I/O 端口拥有独立地址空间，需要专门 I/O 指令访问。 |

- 统一编址也称==内存映射编址==。
	- I/O 端口占用主存地址空间中的一部分地址。
	- 优点是可用普通访存指令访问 I/O 端口。
- 独立编址也称==端口编址==。
	- I/O 地址空间与主存地址空间相互独立。
	- CPU 需要使用专门 I/O 指令访问。

### I/O接口的软件架构
- 用户程序不能直接访问 I/O 设备，通常需要通过[[1.4 计算机软件#1.4 计算机软件|操作系统]]提供的接口和控制程序完成。
- 图中给出的层次：
	- 用户态程序调用与系统无关的 I/O 库函数。
	- 内核态的系统调用进入设备驱动程序。
	- 设备驱动程序通过 I/O 接口控制具体设备。

### I/O接口的分类
- I/O 接口可以按数据传送方式、接口类型、通用性、[[7.1 总线概述#7.1 总线概述|总线]]连接位置和访问设备方式等分类。
