## 8.1 输入输出系统概述
- 输入输出系统用于完成：
	- [[6.1中央处理器概述#6.1中央处理器概述|CPU]] 与外部设备之间的信息交换。
	- 外部设备与[[4.1 存储器概述#4.1.3 主存的基本结构|主存]]之间的信息交换。

- 输入输出系统由硬件系统和软件系统共同组成。

| 部分       | 组成                                          |
| -------- | ------------------------------------------- |
| I/O 硬件系统 | I/O 设备、I/O 接口、I/O 管理部件、[[7.1 总线概述\|I/O总线]]。 |
| I/O 软件系统 | 设备驱动程序、I/O 管理程序、用户程序等。                      |

- 本章主要介绍：
	- I/O 设备的功能及其特性。
	- I/O 接口的功能、结构、编址、软件架构和分类。
	- [[1.3 计算机硬件#1.3 计算机硬件|CPU]] 与 I/O 设备进行信息交换的常见控制方式。
	- 常见 I/O 设备。
