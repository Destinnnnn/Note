## 1.1 计算机系统的组成

- 完整的计算机系统包括：
	- ==硬件==
	- ==软件==
- 硬件是看得见、摸得着的物理设备。
	-  [[1.3 计算机硬件#CPU 内部部件|CPU]]、内存、主板、显卡、固态硬盘、显示器、键盘、鼠标等。
- 软件是在硬件上运行的程序。
- 硬件可以分为：

| 硬件组成 | 说明 |
| --- | --- |
| 主机 | 计算机系统中主要完成计算和控制的部分。 |
| 外设 | 与主机配合完成输入、输出、存储等任务的外部设备。 |

- 软件可以分为：

| 软件类型 | 说明                                   |
| ---- | ------------------------------------ |
| 系统软件 | [[1.4 计算机软件#1.4 计算机软件\|操作系统]]、数据库管理系统、网络系统、标准程序库、语言处理程序、服务程序。 |
| 应用软件 | 科学计算、数据处理、过程控制、事务管理等程序。              |

- ==计算机系统性能的好坏，取决于硬件和软件功能的总和==。
