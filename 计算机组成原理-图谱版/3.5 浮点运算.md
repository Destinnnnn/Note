## 3.5 浮点运算

### 3.5.1 浮点加减法运算

- 浮点加减法的基本步骤：
	1. 对阶。
	2. 尾数运算。
	3. 结果规格化。
	4. 舍入处理。
#### 对阶
- 对阶的原则：==小阶向大阶看齐==。
- 阶码较小的数，其尾数右移，同时阶码增加，直到两个操作数阶码相同。
- 尾数右移可能丢失低位，造成精度损失。
- 不能让大阶向小阶看齐，因为尾数左移可能丢失高位，造成严重数值错误。

#### 尾数运算
- 对阶后，两个操作数阶码相同。
- 将尾数按照定点数加减法进行运算。

#### 结果规格化

| 情况 | 处理 |
| --- | --- |
| 尾数出现 `01...` 或 `10...` 形式 | 需要右规，尾数右移，阶码加 `1`。 |
| 尾数最高数值位与符号位相同 | 需要左规，尾数左移，阶码减 `1`。 |
- 右规可能导致阶码上溢。
- 左规可能导致阶码下溢。

#### 舍入处理

- 图中列出的舍入方式包括：
	- 截断法。
	- 末位恒置 `1` 法。
	- `0` 舍 `1` 入法。
- 使用 `0` 舍 `1` 入后，如果尾数再次变成不规格化，仍需重新规格化处理。

### 3.5.2 IEEE 754 浮点加减法运算

- IEEE 754 浮点数采用移码表示阶码，尾数采用原码表示，并且最高数值位被隐藏，见 [[2.4 浮点数的表示#2.4.3 IEEE 754 浮点数标准|IEEE 754 浮点数标准]]。
- 因此，[[2.4 浮点数的表示#2.4.3 IEEE 754 浮点数标准|IEEE 754]] 浮点加减法与[[2.3 定点数的编码#2.3.2 补码|补码]]尾数的浮点加减法不同：
	- 对阶和规格化过程中，移出的尾数低位要按 IEEE 754 舍入规则处理。
	- 尾数采用[[2.3 定点数的编码#2.3.1 原码|原码]]，需要把符号和数值分开处理。
	- 规格化、溢出和下溢的判定要结合 IEEE 754 的特殊编码。
- 图中列出的舍入方向：
	- 就近舍入。
	- 朝 `0` 方向舍入。
	- 朝 `+∞` 方向舍入。
	- 朝 `-∞` 方向舍入。
- IEEE 754 的结果还需要考虑 `0`、非规格化数、无穷大、`NaN` 等特殊值。

### 3.5.3 浮点乘法运算

- 设两个[[2.4 浮点数的表示#2.4 浮点数的表示|浮点数]]为：
	- `X = 2^E_x × M_x`
	- `Y = 2^E_y × M_y`
- 则：
	- `X × Y = 2^(E_x + E_y) × (M_x × M_y)`

| 步骤 | 说明 |
| --- | --- |
| 阶码相加 | 按定点整数加法处理，可能发生溢出。 |
| 尾数相乘 | 按定点小数乘法处理，结果可能需要规格化和舍入。 |
| 规格化和舍入 | 与浮点加减法类似。 |

- 对 [[2.4 浮点数的表示#2.4.3 IEEE 754 浮点数标准|IEEE 754]] 浮点数：
	- 阶码运算采用[[2.3 定点数的编码#2.3.4 移码|移码]]的运算规则。
	- 尾数相乘时，隐藏位也要参与运算。
	- 采用 IEEE 754 的规格化、溢出检测和处理方法。
	- 图中说明，IEEE 754 浮点乘法运算中不存在向左规格化操作。

### 3.5.4 浮点除法运算

- 设两个[[2.4 浮点数的表示#2.4 浮点数的表示|浮点数]]为：
	- `X = 2^E_x × M_x`
	- `Y = 2^E_y × M_y`
- 则：
	- `X ÷ Y = 2^(E_x - E_y) × (M_x ÷ M_y)`

| 步骤     | 说明                                                      |
| ------ | ------------------------------------------------------- |
| 尾数调整   | 为满足定点小数除法要求，图中在 `M_x>M_y` 时将 `M_x` 右移一位，并将 `E_x` 加 `1`。 |
| 阶码相减   | 按定点整数减法处理，可能发生溢出。                                       |
| 尾数相除   | 按定点小数除法处理，结果可能需要规格化和舍入。                                 |
| 规格化和舍入 | X与浮点加减法类似。                                              |

- 对 [[2.4 浮点数的表示#2.4.3 IEEE 754 浮点数标准|IEEE 754]] 浮点数：
	- 阶码运算采用[[2.3 定点数的编码#2.3.4 移码|移码]]的运算规则。
	- 尾数相除时，隐藏位也要参与运算。
	- 采用 IEEE 754 的规格化、溢出检测和处理方法。
	- 图中说明，IEEE 754 浮点除法运算中不存在向右规格化操作。
