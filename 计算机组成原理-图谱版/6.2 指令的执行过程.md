## 6.2 指令的执行过程
### 6.2.1 指令执行的一般流程
- 计算机的本质任务就是运行存放在[[4.1 存储器概述#4.1.3 主存的基本结构|主存]]中的程序
- cpu内的控制器按照程序对应的机器指令序列逐条执行指令
- cpu上电复位后，就进入了“取指、译码、执行指令”的永久工作循环
 ![[Pasted image 20260630160513.png]]

### 6.2.2 指令周期
- 指令周期是指cpu从[[4.1 存储器概述#4.1.3 主存的基本结构|主存]]取出并且执行一条指令所需的时间
	- 无条件转移指令：只需==取指阶段（包含译码）和执行阶段==。
	- 采用间接[[5.3 寻址方式#5.3 寻址方式|寻址方式]]的指令，需要进行2次访存才能取出操作数。因此需要==取指阶段、间址阶段和执行阶段==。
	- 当指令执行完毕后出现中断请求，cpu进入==中断响应阶段==，进行保存断点、将中断处理程序入口地址送入程序计数器[[1.6 计算机的基本工作原理#1.6 计算机的基本工作原理|PC]]，进而实现当前程序与中断处理程序的切换。

![[Pasted image 20260630161559.png]]
*仅仅是一种典型的指令周期划分方式*
还可能包括：
- [[7.1 总线概述#7.1 总线概述|总线]]周期：完成总线操作以及总线控制权转移所需时间
- I/O周期：完成输入、输出操作所需时间
*==不同指令的指令周期可能不同==*

![[Pasted image 20260630162147.png]]
- 每个指令周期所包含的机器周期的数量、每个机器周期包含的[[1.7 计算机系统的性能指标#1.7.2 与运算速度相关的性能指标|时钟周期]]的数量并不一定是固定的。
	- 定长指令周期（*早期计算机*）：所有指令的==指令周期相同==
	- 变长指令周期（*现代计算机*）：各指令==按照时钟周期进行同步==，时钟周期数量按需分配。
### 6.2.3 指令周期各阶段的数据流
![[Pasted image 20260630162919.png]]

| 小圆圈编号 | 代表的操作                                   |
| ----- | --------------------------------------- |
| ①     | `[[1.6 计算机的基本工作原理#1.6 计算机的基本工作原理|PC]] -> MAR`：程序计数器 PC 中的指令地址送入地址寄存器 MAR。 |
| ②     | `MAR -> 地址总线`：MAR 将地址送到地址总线。            |
| ③     | `地址总线 -> 主存`：主存接收地址总线上的地址。              |
| ④     | `CU -> 控制总线`：控制器 CU 发出读主存控制信号。          |
| ⑤     | `控制总线 -> 主存`：主存接收读命令，准备按地址取出指令。         |
| ⑥     | `主存 -> 数据总线`：主存把取出的指令送到数据总线。            |
| ⑦     | `数据总线 -> MDR`：数据总线上的指令送入存储数据寄存器 MDR。    |
| ⑧     | `MDR -> IR`：MDR 中的指令送入指令寄存器 IR。         |
| ⑨     | `PC + 1 -> PC`：PC 自动加 1，指向下一条指令地址。      |

| ⑦     | `数据总线 -> MDR`：数据总线上的有效地址送入存储数据寄存器 MDR。      |

| ②     | `MAR -> 地址总线`：MAR 将栈地址送到地址总线。                            |

| ⑤     | `控制总线 -> 主存`：主存接收写命令。                                    |
| ⑥     | `PC -> MDR`：将 PC 当前值，即断点地址，送入 MDR。                       |
| ⑦     | `MDR -> 数据总线`：MDR 将断点地址送到数据总线。                           |
| ⑧     | `数据总线 -> 主存`：主存把 PC 的值写入栈中，完成断点保存。                       |
| ⑨     | `[[6.5 异常与中断#6.5 异常与中断|中断]]服务程序入口地址 -> PC`：CU 将中断服务程序的入口地址送入 PC。                 |
