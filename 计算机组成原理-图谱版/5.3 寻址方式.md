## 5.3 寻址方式

### 5.3.1 概述

- 寻址方式是指寻找指令或指令中操作数的==有效地址==的方式。
- 有效地址可以是主存地址，也可以是[[4.8 虚拟存储器#4.8.1 相关概念和基本工作原理|虚拟地址]]。
- 把寻址方式分为：
	- 指令寻址方式。
	- 操作数寻址方式。
- 操作数寻址方式通常由指令中的寻址方式字段 `M` 与形式地址字段 `D` 共同决定。
### 5.3.2 指令寻址方式

| 指令寻址方式 | 中的说明 |
| --- | --- |
| 顺序寻址 | 按指令在主存中的顺序依次执行，取指后 `[[1.6 计算机的基本工作原理#1.6 计算机的基本工作原理|PC]]` 自动形成下一条指令地址。 |
| 跳跃寻址 | 当程序中包含转移/分支指令时，下一条指令地址由转移目标决定。 |

- 顺序寻址中：
	- 若指令字长固定为一个存储字，则取指后可令 `(PC) + 1 -> PC`。
	- 若指令字长为多个字节，则 `PC` 增量与指令长度有关。
- 跳跃寻址中，转移指令会改变 `PC`，使程序转到目标地址继续执行。

### 5.3.3 操作数寻址方式

| 操作数寻址方式 | 中的说明 |
| --- | --- |
| 立即寻址 | 形式地址字段给出的就是操作数本身，操作数与指令一起存放在[[4.1 存储器概述#4.1.3 主存的基本结构|主存]]中。 |
| 直接寻址 | 形式地址字段给出操作数的主存地址，操作数存放在主存中。 |
| 寄存器寻址 | 形式地址字段给出寄存器编号，操作数存放在 [[1.3 计算机硬件#1.3 计算机硬件|CPU]] 的通用寄存器中。 |
| 间接寻址 | 形式地址字段给出的是操作数有效地址所在的主存地址，需访存取得有效地址后再取操作数。 |
| 寄存器间接寻址 | 指令给出寄存器编号，寄存器中保存操作数的主存地址。 |
| 相对寻址 | 形式地址字段给出相对于 `PC` 的偏移量，用 `PC` 内容加偏移量形成有效地址。 |
| 变址寻址 | 指令给出形式地址和变址寄存器编号，二者相加形成有效地址。 |
| 基址寻址 | 指令给出形式地址和基址寄存器编号，二者相加形成有效地址。 |
| 堆栈寻址 | 使用栈顶指针 `SP` 指示栈顶位置，按后进先出 `LIFO` 规则访问。 |

- 立即寻址不需要访问主存取操作数，但形式地址位数限制了立即数的表示范围。
- 直接寻址简单，但寻址范围受地址字段位数限制。
- 间接寻址扩大了寻址范围，但执行时需要多次访存。
- 寄存器寻址速度快，因为操作数在 CPU 内部寄存器中。
- 相对寻址便于程序浮动和相对转移。
- 变址寻址用于数组。
- 基址寻址主要用于程序重定位。
- 复杂寻址方式主要用于复杂指令集计算机 `[[5.5复杂指令集计算机和精简指令集计算机#5.5.1 复杂指令集计算机（CISC)|CISC]]`，例如“相对寻址 + 间接寻址”。
