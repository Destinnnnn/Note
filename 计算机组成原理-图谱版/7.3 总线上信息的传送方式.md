## 7.3 总线上信息的传送方式
- 总线上信息的传送方式包括：
![[Pasted image 20260702150602.png]]

| 方式 | 特点 |
| --- | --- |
| 并行传送 | 多位信息同时传送。 |
| 串行传送 | 信息按位顺序传送。 |
| 并串行传送 | 先并行分组，再按组串行传送。 |
| 分时传送 | 同一组线路在不同时刻传送不同类型的信息。 |

- 并行传送：
	- 一次可以传送多位数据。
	- 线路数量多，适合短距离、高速场景。
- 串行传送：
	- 线路数量少。
	- 适合较长距离传输。
- 串行传送又可分为：

| 类型 | 特点 |
| --- | --- |
| 同步串行通信 | 收发双方在统一时钟节拍下发送和接收。 |
| 异步串行通信 | 发送和接收双方有各自独立时钟，依靠起始位、停止位等实现同步。 |

- 同步串行通信中，收发双方在同一时钟节拍下传送或接收数据。
- 异步串行通信中，常以帧为单位传输。
	- 帧中包含起始位、数据位、校验位和停止位等字段。
- 并串行传送：
	- 先把信息分成若干组。
	- 组内并行传送，组间串行传送。
- 分时传送：
	- 同一组线路在不同时刻传送地址、数据或控制信息。
	- 可以减少线路数量，但需要更复杂的时序控制。
