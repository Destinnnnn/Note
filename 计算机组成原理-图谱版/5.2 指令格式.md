## 5.2 指令格式

### 5.2.1 指令的一般格式和指令字长

- 指令的一般格式包括：
	- 操作码 `OP`。
	- 地址码 `A`。
- 操作码指出要执行的操作，如加、减、移位、传送等。
- 地址码指出操作数的位置或操作结果的存放位置。
- 构成指令的二进制位数称为==指令字长==。
- 根据指令字长是否固定，[[5.1 指令系统概述#5.1 指令系统概述|指令系统]]可分为：

| 类型 | 特点 |
| --- | --- |
| 定长指令系统 | 指令长度固定，结构简单，便于按顺序取指、取码和译码；但平均指令长度较长，冗余状态较多。 |
| 变长指令系统 | 指令长度可变，结构灵活，能缩短常用短指令长度；但取指、译码和控制较复杂。 |

- 图中总结：无论是定长指令系统还是变长指令系统，==指令字长都是字节的整数倍==。
- 根据指令字长与[[1.7 计算机系统的性能指标#1.7.1 基本性能指标|机器字长]]的关系，指令还可分为：
	- 半字长指令。
	- 单字长指令。
	- 多字长指令。

### 5.2.2 指令中的地址码字段

- 地址码字段可根据指令类型和[[5.3 寻址方式#5.3 寻址方式|寻址方式]]指明：
	- 操作数。
	- 操作数的地址。
	- [[4.1 存储器概述#4.1.3 主存的基本结构|主存]]地址。
	- 寄存器编号。
	- 外部设备端口地址。
	- 用于计算地址的偏移量。

| 地址码形式 | 中的说明 |
| --- | --- |
| 三地址指令 | 包含两个源操作数地址和一个目的操作数地址，形如 `(A1) OP (A2) -> A3`。 |
| 二地址指令 | 包含两个地址码，通常一个地址同时保存源操作数和结果，形如 `(A1) OP (A2) -> A1`。 |
| 一地址指令 | 只有一个显式地址，另一个操作数可能隐含在累加器或某个寄存器中。 |
| 零地址指令 | 指令本身不需要显式操作数，或操作数隐含在特定寄存器/栈中。 |

- 若操作数的寻址范围越大，地址码位数就越多，指令就会越长。
- 二地址指令常用于双目运算类操作。
- 一地址指令可隐含另一个操作数或结果位置。
- 零地址指令示例包括：
	- 空操作 `NOP`。
	- 等待指令 `WAIT`。
	- 停机指令 `HLT`。
	- 程序返回指令 `RET`。
### 5.2.3 指令中的操作码字段

#### 定长操作码

- 操作码长度固定，并且其在指令中的位置也是固定的。
- 优点：
	- 指令译码简单。
	- 硬件实现简单。
- 指令系统能够表示的指令数量由操作码位数决定。
- 若指令系统包含 `x` 条指令，操作码位数为 `n`，则应满足：
	- `log2 x ≤ n`

#### 扩展操作码

- 扩展操作码的核心思想：==操作码长度随地址码字段中地址码数量的减少而增加==。
- 在多地址指令中，操作码较短，地址码字段较多。
- 在少地址或零地址指令中，可把原本用于地址码的位置扩展为操作码。
- 扩展操作码可以在指令字长不变的情况下表示更多种指令，但译码设计更复杂。
