## 3.3 定点数的乘法运算

### 3.3.1 无符号数乘法运算的硬件逻辑实现

- 二进制乘法可以类比十进制笔算乘法。
- 机器实现笔算乘法时，会遇到两个问题：
	- 运算过程中产生的多个中间结果需要临时保存。
	- 乘积位数通常是乘数位数的两倍。
- 用“逐位判断乘数最低位、条件加法、右移”的方法实现无符号数乘法。
![[Pasted image 20260701163739.png]]

| 乘数最低位 | 操作 |
| --- | --- |
| `0` | 部分积加 `0`，然后右移。 |
| `1` | 部分积加被乘数，然后右移。 |
![[Pasted image 20260701163858.png]]
- 寄存器关系：
	- `ACC` 保存部分积。
	- `MQ` 保存乘数，并逐步保存乘积低位。
	- `X` 保存被乘数。
	- 计数器控制循环次数。

### 3.3.2 原码乘法运算的硬件逻辑实现

- [[2.3 定点数的编码#2.3.1 原码|原码]]一位乘法将符号位和数值位分开处理。
- 设：
	- `[X]_原 = X_s.X_1X_2...X_n`
	- `[Y]_原 = Y_s.Y_1Y_2...Y_n`
- 乘积符号位：
	- `X_s ⊕ Y_s`
- 乘积数值部分：
	- `|X| × |Y|`
- 因此，原码一位乘法可以复用无符号数乘法的硬件逻辑，再单独处理符号位。

| `MQ_0` | 操作                    |
| ------ | --------------------- |
| `0`    | 仅执行逻辑右移。              |
| `1`    | `ACC` 加上 `X`，再执行逻辑右移。 |
- 计数结束后，将符号位与数值部分组合得到乘积原码。
![[Pasted image 20260702162503.png]]
- 如果每次根据乘数中的两位确定部分积，则循环累加和移位次数约减少一半，可以提高乘法运算速度，这种乘法称为二位乘法。

### 3.3.3 补码乘法运算的硬件逻辑实现

- 使用 Booth 算法实现[[2.3 定点数的编码#2.3.2 补码|补码]]一位乘法。
- Booth 算法在乘数最低位右侧增加一个辅助位，初值为 `0`。
- 每一步根据 `Y_{i+1} - Y_i` 决定对部分积的操作：

| `Y_{i+1} - Y_i` | 操作 |
| --- | --- |
| `0` | 部分积加 `0`。 |
| `1` | 部分积加 `[X]_补`。 |
| `-1` | 部分积减 `[X]_补`，等价于加 `[-X]_补`。 |

- 完成加/减后，部分积和乘数寄存器进行算术右移。
- 计数器控制循环次数，最终得到补码乘积。

### 3.3.4 无符号阵列乘法器

- 无符号阵列乘法器仍基于二进制笔算乘法。
- 各个部分积 `X_iY_j` 由与门并行产生。
- 图中给出阵列结构：
	- 使用 `n × n` 个与门产生部分积。
	- 使用 `n × (n - 1)` 个全加器完成部分积相加。
- 同一行中的全加器没有进位依赖，可以并行执行。
- 不同行之间存在依赖，最终输出 `2n` 位无符号乘积。

### 3.3.5 补码阵列乘法器

- 若直接忽略[[2.3 定点数的编码#2.3.2 补码|补码]]的符号位，把操作数的数值位当作无符号数送入无符号阵列乘法器，得到的数值位不一定正确。
- 图中采用的思路：
	- 以 `n × n` 无符号阵列乘法器为核心。
	- 对被乘数和乘数的数值位设置求补电路。
	- 对 `2n` 位乘积设置求补电路。
	- 根据操作数符号进行修正，得到 `2n` 位补码乘积。
- 求补电路本质上使用补码加减法：
	- 按位取反。
	- 末位加 `1`。
